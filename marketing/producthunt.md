# Product Hunt — Scrapiq launch copy

## Tagline (≤ 60 chars)
URL → clean structured data, one API call

## Description (≤ 260 chars)
Turn any URL into clean text, Markdown, or typed JSON in a single API call. Deterministic parsing first — no headless browser, no selectors, no LLM required. Ships with CLI, Node, LangChain and MCP clients.

## Features (3)
1. One-call extraction — URL → text, Markdown, or schema-typed JSON with a single request.
2. Deterministic parser — grid expansion and footnote resolution, fast and cheap, no token spend.
3. Official clients — CLI, Node.js, LangChain loader, and MCP server out of the box.
